## 1. Síntoma

*Lo que el usuario dijo que vio:*
"Estoy en http://localhost:8080/bpo/gestores como admin, no tengo a la vista la opción de agregar nuevo gestor."

*Pasos para reproducir:*
1. Iniciar sesión como admin
2. Ir a `http://localhost:8080/bpo/gestores`
3. No aparece botón "+ Nuevo Gestor"
4. No aparece opción para habilitar/deshabilitar gestor
5. La vista admin está en otra URL (`/admin/bpo/gestores`) sin enlace en el sidebar

---

## 2. Comportamiento esperado

- Un admin debe ver "+ Nuevo Gestor" en `/bpo/gestores` (una sola URL para todos los roles)
- Un admin debe poder habilitar/deshabilitar un gestor (toggle rápido)
- Debe seguir el patrón "Mis Cursos": mismo template, `sec:authorize` para acciones admin

---

## 3. Comportamiento actual

- `/bpo/gestores` (alumno) no tiene botones admin
- `/admin/bpo/gestores` (admin) existe pero no hay enlace en el sidebar
- No hay toggle para activar/desactivar gestor en ninguna vista
