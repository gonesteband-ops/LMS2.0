# 🐛 Reporte: Bug 003 — Certificaciones: opciones no se renderizan, nota siempre 0.0

> Reporte generado automáticamente por el agente basado en la conversación con el usuario.

## 1. Síntoma

*Lo que el usuario dijo:*
"Al rendir una certificación como alumno, solo funcionan las preguntas de Verdadero/Falso. Las de opción única y opción múltiple no se ven. Además aunque responda bien todas, me da nota 0.0 y aparece como REPROBADO."

*Pasos para reproducir:*
1. Inscribir a un alumno en una certificación que tenga preguntas de opción única y opción múltiple
2. Ir a `http://localhost:8080/certificaciones/{id}/rendir`
3. Las preguntas VF se ven bien, pero las de opción única y múltiple no muestran opciones
4. Responder solo las VF y entregar
5. Resultado: nota 0.0, REPROBADO

---

## 2. Comportamiento esperado

- Los 3 tipos de pregunta (VF, opción única, opción múltiple) deben renderizar sus opciones correctamente
- Si el alumno responde bien, debe aprobar con nota >= nota mínima
- Opción múltiple: debe corregir como "todo o nada" (todas las correctas marcadas y ninguna incorrecta)

---

## 3. Comportamiento actual

- Opción única y múltiple: no se renderizan (pantalla en blanco en esa sección)
- Nota: siempre 0.0 aunque se responda bien
- Opción múltiple: nunca se corrige correctamente

## 4. Evidencia recolectada por el agente

### Archivos relevantes

| Archivo | Línea(s) | Problema |
|---|---|---|
| `src/main/resources/templates/certificaciones/rendir.html` | 51-69 | Usa `document.write()` dentro de `<script th:inline>` que SOBREESCRIBE el DOM cuando el template se procesa después del render inicial |
| `src/main/java/com/lms/service/CertificacionService.java` | 321-343 | `verificarRespuesta()` no maneja arrays (opción múltiple envía `["A","B"]` pero el método espera un String) |

### Causas raíz

**Causa 1 — `document.write()`:** El template usa `<script th:inline="javascript">` con `document.write()` para inyectar las opciones. Thymeleaf procesa el `[[${p.opciones}]]` como inlining JavaScript dentro del HTML. Cuando el navegador ejecuta `document.write()` después de que el DOM ya fue parseado, **reemplaza todo el contenido de la página**. Por eso solo VF funciona (usa HTML plano, no JS).

**Causa 2 — Nota 0.0:** Consecuencia directa de la Causa 1. Si las opciones no se renderizan, el alumno no puede seleccionar nada. `respuestasBody` llega vacío al backend. `verificarRespuesta` nunca encuentra match. `notaTotal = 0` → `notaFinal = 0.0`.

**Causa 3 — Opción múltiple no corregible:** `verificarRespuesta` recibe `Object respuestaAlumno`. Para opción múltiple, el frontend envía un array `["A", "B"]` como `ArrayList<String>`. El método compara `respuestaAlumno.toString()` contra `val.toString()`. `["A", "B"].toString()` da `"A, B"` que nunca coincide con una opción individual.
