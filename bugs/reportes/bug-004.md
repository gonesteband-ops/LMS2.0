# Reporte de Bug: Inscripcion usuarios — error 403, ERR_EMPTY_RESPONSE y carga masiva no encuentra RUTs

---

## 1. Inscribir usuario individual — Error 403 + server crash

POST /api/v1/cursos/{cursoId}/inscribir
Mensaje: "No tiene permisos para acceder a este recurso"
Consola F12: net::ERR_EMPTY_RESPONSE (servidor corta conexion)

### Causa
`InscripcionController.java:48` usa `@PreAuthorize("hasAuthority('INSCRIPCION_CREAR')")`.
El admin tiene ROLE_ADMIN pero quizas no el permiso granular INSCRIPCION_CREAR.
ERR_EMPTY_RESPONSE indica que el servidor CRASHEA, posiblemente por un error no manejado.

---

## 2. Inscripcion masiva CSV — 0 inscritos, todos "no encontrados"

CSV con RUTs tipo 11111111-1, 18478280-8.
El sistema reporta "0 inscritos, 7 no encontrados" aunque los usuarios existen.

### Causa
`InscripcionService.java:263` usa `UUID.fromString(linea)` que FALLA para RUTs.
El codigo de carga masiva NO reusa `resolverIdentificador()` (que SI soporta RUT, email y UUID).
Tiene su propia logica limitada que solo acepta UUIDs y emails.
