# 🐛 Reporte de Mejora UX: Dashboard del Estudiante

---

## 1. ¿Qué pasó?

En la vista principal del rol **ESTUDIANTE** (Dashboard), se detectaron oportunidades de mejora en la experiencia de usuario:

1. El título superior indica **"Panel Principal"**, un concepto muy administrativo que resulta poco cercano e intuitivo para el alumno.
2. Las cuatro tarjetas estadísticas superiores son puramente informativas y no funcionan como enlaces de acceso rápido, lo que obliga al usuario a navegar mediante el menú lateral.
3. En pantallas compactas o dispositivos móviles, la barra lateral de navegación ocupa espacio visual y carece de un control colapsable (menú hamburguesa con las 3 líneas).
4. Al evaluar la funcionalidad de enlace para la tarjeta de **"Evaluaciones Pendientes"**, se debe asegurar que no duplique el destino de "Cursos Activos", debiendo apuntar directamente al listado o filtrado específico de evaluaciones pendientes del alumno para darle utilidad real.
5. **(Bug adicional)** El backend computa `evaluacionesPendientes` pero no lo incluye en la respuesta JSON del endpoint `/api/v1/dashboard/resumen`, por lo que el frontend siempre recibe `undefined`.

---

## 2. ¿Dónde pasó?

- **Vista afectada:** `src/main/resources/templates/dashboard/index.html`
- **Layout de navegación:** `src/main/resources/templates/fragments/sidebar.html`, `fragments/header.html`
- **Backend API:** `src/main/java/com/lms/controller/DashboardController.java`
- **CSS:** `src/main/resources/static/css/layout.css`
- **JavaScript:** `src/main/resources/static/js/app.js`

## 3. Comportamiento esperado (Desired)

| # | Mejora | Detalle |
|---|---|---|
| 1 | **Título amigable** | Cambiar "Panel Principal" por **"Inicio"** (en el `<h1>`, sidebar y nav pills). |
| 2 | **Tarjetas clickeables** | Las 4 tarjetas KPI deben ser enlaces: Cursos Activos → `/cursos`, Documentos → `/dashboard/documentos`, Firmas → `/dashboard/firmas`, Evaluaciones Pendientes → nueva página `/dashboard/evaluaciones-pendientes`. Efecto hover con `translateY(-2px)` y sombra. |
| 3 | **Menú hamburguesa** | Botón de 3 líneas en el header (visible siempre) que colapsa/expande la barra lateral en todos los tamaños de pantalla. Al colapsar, el contenido ocupa el ancho completo. |
| 4 | **Página "Evaluaciones Pendientes"** | Nueva página dedicada que lista TODAS las evaluaciones pendientes del estudiante a través de todos sus cursos inscritos, con botón "Rendir Evaluación" por cada una. |
| 5 | **Bug backend** | Agregar `"evaluacionesPendientes"` al `Map.of(...)` en `DashboardController.obtenerResumen()`. |
