# 🐛 Reporte de Bug: Usuarios/Cursos cargando + Compartir gestor + Vista alumno

---

## Tarea 1: Usuarios/Cursos se queda en "Cargando..."

### Síntoma
- `/admin/usuarios` muestra "Cargando usuarios..." permanentemente
- `/cursos` muestra "Cargando cursos..." permanentemente
- F12 muestra: "Content unavailable. Resource was not cached"

### Causa raíz
Los controladores `HomeController.adminUsuarios()` y `HomeController.cursos()` **no tienen `@PreAuthorize`**, por lo que cualquier usuario autenticado puede acceder a la página. Pero el HTMX request a `/hx/admin/usuarios` requiere `ADMIN/SUPERADMIN`. Si el usuario no tiene esos roles o la sesión expiró, el request falla silenciosamente.

### Solución
Agregar `@PreAuthorize` a los endpoints de página para que solo usuarios autorizados accedan.
