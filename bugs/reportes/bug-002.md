# 🐛 Reporte de Bug: Editor de curso — datos en blanco, error 403 y estado no cambia

---

## 1. Sintoma (que viste)

1. Ir a `http://127.0.0.1:8080/cursos/editar?id=eb91cff9-d38a-47b6-8017-ceb097f67e28`
2. La categoria aparece **en blanco** (deberia mostrar la categoria guardada)
3. La duracion estimada en minutos aparece **en blanco**
4. El estado siempre muestra "Borrador" aunque se haya guardado como "Publicado" o "Archivado"
5. Al hacer clic en "Actualizar curso" aparece el error Forbidden
6. El curso no se actualiza

---

## 2. Comportamiento esperado

1. Al editar un curso, todos los campos deben cargarse con los valores existentes
2. El select de estado debe mostrar el valor actual del curso
3. Al hacer clic en "Actualizar curso" debe guardar los cambios sin error 403
4. El estado seleccionado debe persistir despues de guardar

---

## 3. Comportamiento actual

- **Categoria y duracion en blanco:** `cargarCurso()` no asigna `categoria` ni `duracion` desde la respuesta JSON
- **Error 403 Forbidden:** El PUT a `/api/v1/cursos/{id}` es rechazado
- **Estado siempre "borrador":** El payload JSON en `guardarCurso()` no incluye `estado`. `CursoService.actualizarCurso()` nunca actualiza estado. `CursoRequest.java` no tiene campo `estado`.

---

## 4. Evidencia

- PUT `/api/v1/cursos/{id}` → HTTP 403 Forbidden
- `categoria` y `duracion` no se asignan en `cargarCurso()`
- `estado` no esta en el objeto `payload`
- `CursoRequest.java` no tiene campo `estado`
