# Reporte de Bug: No compila el proyecto con Docker

---

## 1. Que paso?

Ejecute `docker compose up --build -d` para iniciar el servidor y la compilacion fallo.
No puedo ver los cambios en http://localhost:8080.

---

## 2. Que deberia pasar?

El servidor deberia iniciar sin errores y mostrar la aplicacion en http://localhost:8080.

---

## 3. Que paso realmente?

Al compilar, Maven tiro estos errores:

**Faltan 4 metodos en ContenidoBPOService.java que los controladores intentan usar:**

| Metodo que falta | Donde lo llaman |
|---|---|
| obtenerResumen(usuarioId) | ContenidoBPOController.java (lineas 38 y 46) |
| buscarConFiltros(usuarioId, q, tipo, estado) | ContenidoBPOController.java (linea 58) |
| crearContenido(dto, usuarioId, cuentaId) | ContenidoBPOApiController.java (linea 50) y ContenidoBPOController.java (linea 94) |
| cambiarEstado(id, estado, usuarioId) | ContenidoBPOController.java (linea 103) |

---

## 4. Evidencia

**Error completo en consola:**
```
[ERROR] COMPILATION ERROR : 
[ERROR] cannot find symbol: method crearContenido
[ERROR] cannot find symbol: method obtenerResumen
[ERROR] cannot find symbol: method buscarConFiltros
[ERROR] cannot find symbol: method cambiarEstado
[ERROR] -> [Help 1]
```

---

## 5. Contexto

- Comando: docker compose up --build -d
- Rama: 002-gestor-contenidos-bpo
- Sistema: Spring Boot 3.3.0, Java 17, Maven

- src/main/java/com/lms/service/bpo/ContenidoBPOService.java  --  le faltan metodos
