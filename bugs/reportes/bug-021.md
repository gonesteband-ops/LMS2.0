## TAREA B — Limpieza y Simplificación de Roles

### Problema
Actualmente hay **8 roles**, varios redundantes o sin usuarios:
- **ADMIN** (sistema, 0 usuarios) — duplica a SUPERADMIN
- **SUPERADMIN** (sistema, 1 usuario: admin@lms.cl)
- **INSTRUCTOR** (sistema, 1 usuario: instructor@lms.cl)
- **ESTUDIANTE** (sistema, ~12 usuarios)
- **BPO_ADMIN** (no sistema, 1 usuario: admin@lms.cl) — CRUD total, igual que SUPERADMIN
- **BPO_SUPERVISOR** (no sistema, 0 usuarios) — CRUD, casi igual a BPO_ADMIN
- **BPO_AGENTE** (no sistema, 0 usuarios) — solo lectura
- **ROL DE PRUEBA** (no sistema, 0 usuarios) — sobrante de pruebas

### Propuesta: Reducir a 5 roles

| Rol | Descripción | Permisos clave |
|---|---|---|
| **SUPERADMIN** | Unifica SUPERADMIN + ADMIN + BPO_ADMIN | Todo: LMS + BPO + roles + certificaciones |
| **INSTRUCTOR** | Sin cambios | Cursos, evaluaciones, BPO_CONTENIDO_LEER |
| **ESTUDIANTE** | + Certificaciones | Leer cursos, rendir evaluaciones, rendir certificaciones |
| **BPO_AGENTE** | Solo lectura BPO | BPO_CONTENIDO_LEER |
| **GESTOR_CURSOS** | Nuevo (opcional) | Si se necesita un perfil intermedio |

### Roles a eliminar (4):
`ADMIN`, `BPO_ADMIN`, `BPO_SUPERVISOR`, `ROL_DE_PRUEBA`

### Nuevos permisos a crear:
`CERTIFICACION_LEER`, `CERTIFICACION_RENDIR`, `CERTIFICACION_ADMIN`

### Migración V30 propuesta
```sql
-- 1. Migrar usuarios de ADMIN, BPO_ADMIN, BPO_SUPERVISOR a SUPERADMIN
INSERT INTO usuarios_roles (usuario_id, rol_id)
SELECT ur.usuario_id, (SELECT id FROM roles WHERE nombre = 'SUPERADMIN')
FROM usuarios_roles ur JOIN roles r ON r.id = ur.rol_id
WHERE r.nombre IN ('ADMIN', 'BPO_ADMIN', 'BPO_SUPERVISOR')
  AND NOT EXISTS (
    SELECT 1 FROM usuarios_roles ur2
    WHERE ur2.usuario_id = ur.usuario_id AND ur2.rol_id = (SELECT id FROM roles WHERE nombre = 'SUPERADMIN')
  );

-- 2. Eliminar roles_permisos de roles a eliminar
DELETE FROM roles_permisos WHERE rol_id IN (SELECT id FROM roles WHERE nombre IN ('ADMIN', 'BPO_ADMIN', 'BPO_SUPERVISOR', 'ROL DE PRUEBA'));

-- 3. Eliminar usuarios_roles de roles a eliminar
DELETE FROM usuarios_roles WHERE rol_id IN (SELECT id FROM roles WHERE nombre IN ('ADMIN', 'BPO_ADMIN', 'BPO_SUPERVISOR', 'ROL DE PRUEBA'));

-- 4. Eliminar roles
DELETE FROM roles WHERE nombre IN ('ADMIN', 'BPO_ADMIN', 'BPO_SUPERVISOR', 'ROL DE PRUEBA');

-- 5. Agregar nuevos permisos de certificaciones
INSERT INTO permisos (id, nombre, recurso, accion, descripcion)
SELECT gen_random_uuid(), v.nombre, v.recurso, v.accion, v.descripcion
FROM (VALUES
    ('CERTIFICACION_LEER', 'certificacion', 'LEER', 'Leer certificaciones'),
    ('CERTIFICACION_RENDIR', 'certificacion', 'RENDIR', 'Rendir certificaciones'),
    ('CERTIFICACION_ADMIN', 'certificacion', 'ADMIN', 'Administrar certificaciones')
) AS v(nombre, recurso, accion, descripcion)
WHERE NOT EXISTS (SELECT 1 FROM permisos p WHERE p.nombre = v.nombre);

-- 6. Asignar CERTIFICACION_ADMIN a SUPERADMIN e INSTRUCTOR
INSERT INTO roles_permisos (rol_id, permiso_id)
SELECT r.id, p.id FROM roles r, permisos p
WHERE r.nombre = 'SUPERADMIN' AND p.nombre IN ('CERTIFICACION_LEER', 'CERTIFICACION_RENDIR', 'CERTIFICACION_ADMIN')
  AND NOT EXISTS (SELECT 1 FROM roles_permisos rp WHERE rp.rol_id = r.id AND rp.permiso_id = p.id);

-- 7. Asignar CERTIFICACION_LEER y CERTIFICACION_RENDIR a ESTUDIANTE
INSERT INTO roles_permisos (rol_id, permiso_id)
SELECT r.id, p.id FROM roles r, permisos p
WHERE r.nombre = 'ESTUDIANTE' AND p.nombre IN ('CERTIFICACION_LEER', 'CERTIFICACION_RENDIR')
  AND NOT EXISTS (SELECT 1 FROM roles_permisos rp WHERE rp.rol_id = r.id AND rp.permiso_id = p.id);
```
